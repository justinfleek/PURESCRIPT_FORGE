# Lean Experiments

Experimental Lean4 projects for formal verification research.

## Components
- `src/compass-lean` - Compass navigation proofs
- `src/lattice-lean` - Lattice theory
- `src/leandojo-lean` - LeanDojo integration
- `src/llm-agent-lean` - LLM agent proofs
- `src/mathanalysis-lean` - Math analysis
- `src/mathlib-demo-lean` - Mathlib demos
- `src/raytracer-lean` - Raytracer example

## Status
Research/experimental - not production ready.
